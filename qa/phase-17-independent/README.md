This QA-only package gates Book I — The First Covenant, Chronicle, story-driven physical Village discovery, durable Village projections, tutorials, and all 38 cast actors. It inherits but does not implement the accepted Phase 12–16 coordinator, tutorial, facility-board, archive, and Restaurant seams.

Package contract:

```sh
node qa/phase-17-independent/verify.mjs --package-only
```

Candidate contract:

```sh

```

Serve the repository root and open `qa/phase-17-independent/` for the live gate. Five isolated memory-backed realms cover 320×568, 390×844, 1024×768, reduced motion, and 130-percent localized-copy expansion. Native storage is instrumented and must remain untouched.

Production may expose `window.__EVERSTEAD_PHASE_17_QA__` only behind the local/query-gated destructive QA boundary. The exact bridge is frozen in the contract document. On the preimplementation base, its absence produces the precise fail-closed `bridge-present` and `phase17-contract-unavailable` result pair in each realm.

The live runner queries actual Chronicle and scene DOM, navigation count, focus movement/return, keyboard activation, Escape, target sizes, accessible status, overflow, and reduced-motion styles. It also verifies `player.wayfarer` as a separate Campaign/title character, never a roster/assignment unit, and requires a silhouette/static fallback until a genuine transparent Campaign asset is approved.

Passive regression comparisons use one frozen timestamp inside the same fixture and explicitly exclude `day`, `boostDay`, `lastGoldAt`, and `lastSeen`; they do not freeze legitimate date rollover across unrelated fixture resets. The reduced-motion realm uses the production-observable `data-everstead-reduced-motion="reduce"` root contract plus actual computed CSS and never monkey-patches `matchMedia` as its own evidence. Normalized bridge output is necessary for save and deterministic ordering assertions but does not replace actual-DOM inspection.
