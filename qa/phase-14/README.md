Run from the repository root with the bundled Node.js runtime:

```sh
node qa/phase-14/probe.mjs
```

It verifies the additive Phase 14 definition surface, all four new fixtures, detached corruption refusal, untouched fixture values, clone-only Campaign pacing through the real gates and deterministic progression, reward-impact measurement, bounded Legacy and carried-progress claim output, and normalized accessibility/presentation output.
