# Phase 18–19 Product Policy Candidate

This package turns the Apothecary and Schoolhouse's 86 deliberately undecided
design slots into an executable, reviewable candidate. It is **not approved
authority** and cannot enable production. The accepted files in
`design/phase-18-19/` remain unchanged, null, and fail closed.

## Run

```sh
python3 design/phase-18-19-policy-candidate/generate_reward_table.py --check
python3 design/phase-18-19-policy-candidate/simulate.py --check
python3 design/phase-18-19-policy-candidate/validate.py
```

`policy-candidate.json` is the proposed product policy. The fixed table and
simulation output are mechanically regenerated by the adjacent scripts.
`decision-ledger.json` separates accepted facts, candidate recommendations,
and the six choices still requiring root approval.

Approval must create a new immutable approved-policy package. It must not
change this candidate in place or promote candidate QA state into a live save.
