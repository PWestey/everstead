# Everstead navigation art

These six original assets were generated for Everstead with OpenAI's built-in image generation tool on 2026-09-04. They do not contain third-party game artwork.

The five transparent route emblems share this direction:

> Everstead mobile fantasy RPG navigation art. Refined hand-painted game UI illustration, dark moonlit navy and charcoal, warm antique gold and bronze edges, subtle teal Waystone glow, painterly but crisp at 32 pixels, premium storybook-fantasy finish. Centered isolated emblem with generous transparent padding. No words, letters, numbers, watermark, border frame, square background, people, or faces. Genuinely transparent background with clean alpha edges.

Subjects, in navigation order:

- `village.png`: a welcoming hill village, peaked hall, glowing windows, and winding path.
- `oaths.png`: a rolled covenant scroll, wax seal, and luminous oath rune.
- `fellowship.png`: three linked heraldic crests representing the joined roster.
- `adventure.png`: a compass rose, winding mountain road, and distant star.
- `more.png`: a leather satchel with map, key, and journal tabs.

The housing texture uses this direction:

> Seamless close-up material texture for the entire bottom navigation; dark weathered walnut, subtle fantasy filigree, thin antique bronze inlay, faint teal Waystone flecks, and a worn-leather undertone. Even low contrast, with no compartments, icons, objects, symbols, text, borders, perspective, vignette, or UI screenshot.

The source generations are retained in the Codex generated-image workspace. Runtime copies were resized without creative alteration: the route emblems are 256×256 PNGs with alpha, and `nav-frame.png` is a 1024×242 opaque PNG. The neutral housing deliberately has no baked labels, route icons, selected slot, or dividers so it remains compatible with Everstead's unequal responsive navigation columns.
