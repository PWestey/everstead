# Fellow panel illustrations

Original code-native SVG illustrations created for Everstead. No screenshot pixels or third-party game assets are included.

Five local tab illustrations and six distinct Relic illustrations. All have 160×160 view boxes and remain resolution-independent. Decorative tab images use empty alt text; the Relic detail image is named.

The Isekai screenshots supplied by the user informed hierarchy, framing, and the art-first presentation—not mechanics. EXP, shards, equipment, and saves remain owned by their existing handlers.
